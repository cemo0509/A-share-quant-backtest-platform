# A股量化回测平台 - 测试指南

## 测试环境要求
- Python 3.8+
- Node.js 16+
- 足够的磁盘空间（至少2GB）
- 稳定的网络连接（用于下载数据）

## 测试步骤

### 一、环境准备

#### 1. 安装Python依赖
```bash
cd backend
pip install -r requirements.txt
```

#### 2. 安装前端依赖
```bash
cd frontend
npm install
```

## 附录：测试用策略代码

### 示例1：简单的自定义策略
```python
import backtrader as bt

class SimpleStrategy(bt.Strategy):
    params = (("period", 20),)
    
    def __init__(self):
        self.sma = bt.indicators.SMA(period=self.params.period)
    
    def next(self):
        if not self.position:
            if self.data.close[0] > self.sma[0]:
                self.buy(size=100)
        else:
            if self.data.close[0] < self.sma[0]:
                self.close()

def get_strategy_class():
    return SimpleStrategy
```

### 示例2：直接继承bt.Strategy的策略
```python
import backtrader as bt

class MyStrategy(bt.Strategy):
    def __init__(self):
        self.sma = bt.indicators.SMA(period=20)
    
    def next(self):
        if self.data.close[0] > self.sma[0]:
            self.buy(size=100)

def get_strategy_class():
    return MyStrategy
```
