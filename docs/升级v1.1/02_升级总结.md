## 升级内容详解

### 一、新增策略（3个）

#### 1. 均值回归策略 (MeanReversionStrategy)
**文件位置**：`backend/core/strategies/mean_reversion.py`

**策略原理**：
- 计算价格与均值的偏离度（Z-Score）
- 当价格低于均值一定标准差时买入（超卖）
- 当价格高于均值一定标准差时卖出（超买）
- 结合RSI指标确认

**适用场景**：震荡市场

**参数列表**：
- `period`：均值计算周期（默认20）
- `std_dev`：标准差倍数（默认2.0）
- `rsi_period`：RSI周期（默认14）
- `rsi_oversold`：RSI超卖线（默认30）
- `rsi_overbought`：RSI超买线（默认70）
- `max_hold_days`：最大持有天数（默认10）
- `profit_target`：止盈目标（默认0.03，即3%）
- `stop_loss`：止损比例（默认0.02，即2%）

#### 2. 动量策略 (MomentumStrategy)
**文件位置**：`backend/core/strategies/momentum.py`

**策略原理**：
- 计算动量指标（N日收益率）
- 动量 > 阈值时买入（上涨趋势）
- 动量 < -阈值时卖出（下跌趋势）
- 结合均线确认趋势

**适用场景**：趋势市场

**参数列表**：
- `momentum_period`：动量计算周期（默认20）
- `ma_period`：趋势确认均线（默认50）
- `momentum_threshold`：动量阈值（默认0.02，即2%）
- `profit_target`：止盈目标（默认0.05，即5%）
- `stop_loss`：止损比例（默认0.03，即3%）
- `trailing_stop`：追踪止损（默认0.02，即2%）
- `max_hold_days`：最大持有天数（默认30）
- `position_size`：仓位比例（默认0.3，即30%）

#### 3. 网格交易策略 (GridTradingStrategy)
**文件位置**：`backend/core/strategies/grid_trading.py`

**策略原理**：
- 设置中枢价格（固定或动态）
- 在中枢上方设置卖出网格，下方设置买入网格
- 价格每下跌一个网格，买入一定数量
- 价格每上涨一个网格，卖出一定数量

**适用场景**：震荡市场（横盘）

**参数列表**：
- `grid_count`：网格数量（单边，默认10）
- `grid_spacing`：网格间距（默认0.01，即1%）
- `base_position`：基准仓位比例（默认0.5，即50%）
- `single_position`：单格交易仓位（默认0.05，即5%）
- `center_type`：中枢类型（fixed/dynamic，默认dynamic）
- `center_price`：固定中枢价格（默认0，表示使用当前价）
- `dynamic_period`：动态中枢周期（默认20）
- `min_spread`：最小价差（默认0.005，即0.5%）
- `max_position`：最大仓位（默认0.95，即95%）

### 二、策略比较功能

#### 1. 后端API
**端点**：`POST /api/backtest/compare`

**请求参数**：
```json
{
  "strategies": ["dual_ma", "rsi", "mean_reversion"],
  "symbol": "000001",
  "start_date": "20240101",
  "end_date": "20241231",
  "cash": 1000000,
  "commission": 0.0003,
  "slippage": 0.001
}
```

**响应**：
```json
{
  "status": "ok",
  "data": [
    {
      "strategy": "dual_ma",
      "status": "ok",
      "data": { ... }  // 回测结果
    },
    {
      "strategy": "rsi",
      "status": "ok",
      "data": { ... }
    }
  ]
}
```

#### 2. 前端页面
**文件位置**：`frontend/src/pages/Compare.tsx`

**功能**：
- 选择多个策略进行比较（至少2个）
- 设置回测参数（股票代码、时间范围、初始资金等）
- 显示比较结果表格
- 比较指标：总收益率、夏普比率、最大回撤、交易次数等

**访问路径**：左侧菜单 → "策略比较"
