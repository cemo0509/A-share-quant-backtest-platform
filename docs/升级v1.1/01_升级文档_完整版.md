## 升级背景

### 项目现状
A股量化回测平台v1.0已经发布，包含以下核心功能：
- 8个预定义策略（双均线、布林带、RSI、MACD、海龟、KDJ、均线多头、成交量突破）
- 自定义策略编辑器
- 回测引擎
- 数据管理
- 参数优化

### 存在的问题
1. **策略数量不足**：只有8个策略，无法满足不同市场环境的需求
2. **缺少策略比较功能**：用户无法直观比较不同策略的表现
3. **数据导出不便**：回测结果无法导出，不利于进一步分析
4. **自定义策略限制**：必须继承`BaseStrategy`，不能直接继承`bt.Strategy`

### 升级必要性
1. 添加更多经典策略，提升平台实用性
2. 添加策略比较功能，提升分析能力
3. 添加数据导出功能，提升用户体验

## 升级内容

### 一、新增策略（3个）

#### 1. 均值回归策略 (MeanReversionStrategy)
**文件**：`backend/core/strategies/mean_reversion.py`

**策略原理**：
- 计算价格与均值的偏离度（Z-Score）
- 当价格低于均值一定标准差时买入（超卖）
- 当价格高于均值一定标准差时卖出（超买）
- 结合RSI指标确认

**适用场景**：震荡市场

**参数**：
| 参数名 | 说明 | 默认值 | 范围 |
|--------|------|--------|------|
| period | 均值计算周期 | 20 | 10-50 |
| std_dev | 标准差倍数 | 2.0 | 1.0-3.0 |
| rsi_period | RSI周期 | 14 | 5-30 |
| rsi_oversold | RSI超卖线 | 30 | 10-50 |
| rsi_overbought | RSI超买线 | 70 | 50-90 |
| max_hold_days | 最大持有天数 | 10 | 3-30 |
| profit_target | 止盈目标 | 0.03 | 0.01-0.10 |
| stop_loss | 止损比例 | 0.02 | 0.01-0.05 |

#### 2. 动量策略 (MomentumStrategy)
**文件**：`backend/core/strategies/momentum.py`

**策略原理**：
- 计算动量指标（N日收益率）
- 动量 > 阈值时买入（上涨趋势）
- 动量 < -阈值时卖出（下跌趋势）
- 结合均线确认趋势

**适用场景**：趋势市场

**参数**：
| 参数名 | 说明 | 默认值 | 范围 |
|--------|------|--------|------|
| momentum_period | 动量计算周期 | 20 | 10-50 |
| ma_period | 趋势均线周期 | 50 | 20-100 |
| momentum_threshold | 动量阈值 | 0.02 | 0.01-0.05 |
| profit_target | 止盈目标 | 0.05 | 0.02-0.15 |
| stop_loss | 止损比例 | 0.03 | 0.01-0.08 |
| trailing_stop | 追踪止损 | 0.02 | 0.01-0.05 |
| max_hold_days | 最大持有天数 | 30 | 10-60 |
| position_size | 仓位比例 | 0.3 | 0.1-0.5 |

#### 3. 网格交易策略 (GridTradingStrategy)
**文件**：`backend/core/strategies/grid_trading.py`

**策略原理**：
- 设置中枢价格（固定或动态）
- 在中枢上方设置卖出网格，下方设置买入网格
- 价格每下跌一个网格，买入一定数量
- 价格每上涨一个网格，卖出一定数量

**适用场景**：震荡市场（横盘）

**参数**：
| 参数名 | 说明 | 默认值 | 范围 |
|--------|------|--------|------|
| grid_count | 网格数量（单边） | 10 | 5-20 |
| grid_spacing | 网格间距 | 0.01 | 0.005-0.03 |
| base_position | 基准仓位 | 0.5 | 0.2-0.8 |
| single_position | 单格交易仓位 | 0.05 | 0.02-0.10 |
| center_type | 中枢类型 | dynamic | fixed/dynamic |
| center_price | 固定中枢价格 | 0.0 | 0-10000 |
| dynamic_period | 动态中枢周期 | 20 | 10-50 |
| min_spread | 最小价差 | 0.005 | 0.002-0.01 |
| max_position | 最大仓位 | 0.95 | 0.5-1.0 |

### 四、代码修复

#### 1. 问题描述
自定义代码回测接口要求策略类必须定义`printlog`参数，但直接继承`bt.Strategy`的类可能没有定义这个参数，导致错误。

#### 2. 解决方案
在`backend/core/engine.py`中添加参数过滤逻辑：
1. 检查策略类的`params`属性
2. 如果是`AutoInfoClass`，使用`_getkeys()`获取参数名
3. 如果是元组，直接解析
4. 只传递策略类定义的参数

#### 3. 代码修改
**文件**：`backend/core/engine.py`（第97-125行）

**核心代码**：
```python
# 过滤掉策略类没有定义的参数
if hasattr(strategy_cls, 'params'):
    params_attr = strategy_cls.params
    
    # 检查 params 是否是 AutoInfoClass（有 _getkeys 方法）
    if hasattr(params_attr, '_getkeys'):
        # AutoInfoClass: 使用 _getkeys() 获取参数名
        valid_param_names = list(params_attr._getkeys())
    elif isinstance(params_attr, (tuple, list)):
        # 原始元组格式
        valid_param_names = [p[0] for p in params_attr if isinstance(p, (tuple, list))]
    else:
        # 未知格式，不过滤
        valid_param_names = None
    
    if valid_param_names is not None:
        filtered_params = {k: v for k, v in bt_params.items() if k in valid_param_names}
        bt_params = filtered_params
```
