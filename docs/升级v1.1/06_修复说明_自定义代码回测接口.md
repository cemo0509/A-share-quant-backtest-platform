# 修复说明：自定义代码回测接口支持直接继承 bt.Strategy 的策略类

## 问题描述
自定义代码回测接口要求策略类必须继承 `BaseStrategy`，否则会出现错误：
```
MyStrategy.__init__() got an unexpected keyword argument 'printlog'
```

## 根本原因
1. `BaseStrategy` 定义了 `params = (("printlog", False),)`
2. 前端或引擎在调用 `cerebro.addstrategy()` 时，会传递 `printlog` 参数
3. 如果策略类直接继承 `bt.Strategy` 而没有定义 `printlog` 参数，Backtrader 会报错

## 解决方案
修改 `backend/core/engine.py` 中的 `run_backtest()` 函数，在添加策略之前过滤参数：
- 只传递策略类定义的参数
- 过滤掉策略类没有定义的参数（如 `printlog`）

## 修改的文件

### 1. backend/core/engine.py
修改了 `run_backtest()` 函数中的参数处理逻辑（第 97-125 行）：

```python
# 4. 添加策略（注入参数）
bt_params = {**params}

# 过滤掉策略类没有定义的参数
# Backtrader 使用元类系统，strategy_cls.params 是一个 AutoInfoClass
# 我们需要正确获取策略类定义的参数列表
if hasattr(strategy_cls, 'params'):
    params_attr = strategy_cls.params
    
    # 检查 params 是否是 AutoInfoClass（有 _getkeys 方法）
    if hasattr(params_attr, '_getkeys'):
        # AutoInfoClass: 使用 _getkeys() 获取参数名
        valid_param_names = list(params_attr._getkeys())
    elif isinstance(params_attr, (tuple, list)):
        # 原始元组格式: (("param1", default1), ("param2", default2), ...)
        valid_param_names = [p[0] for p in params_attr if isinstance(p, (tuple, list))]
    else:
        # 未知格式，不过滤
        valid_param_names = None
    
    if valid_param_names is not None:
        filtered_params = {k: v for k, v in bt_params.items() if k in valid_param_names}
        if len(filtered_params) != len(bt_params):
            removed = set(bt_params.keys()) - set(filtered_params.keys())
            print(f"DEBUG: filtered params, removed {removed}")
        bt_params = filtered_params

print(f"DEBUG: strategy_cls={strategy_cls.__name__}, bt_params keys={list(bt_params.keys())}")
cerebro.addstrategy(strategy_cls, **bt_params)
```

### 2. backend/core/strategies/custom_manager.py
简化了 `load_strategy_from_code()` 函数，移除了动态添加 `printlog` 参数的逻辑：

```python
# 查找策略类
for attr_name in dir(module):
    attr = getattr(module, attr_name)
    if (
        isinstance(attr, type)
        and issubclass(attr, bt.Strategy)
        and attr is not bt.Strategy
    ):
        print(f"DEBUG: found strategy class {attr_name}")
        
        # 注意：不需要动态添加 printlog 参数
        # engine.py 会自动过滤掉策略类没有定义的参数
        # 这样可以支持直接继承 bt.Strategy 的策略类
        
        return attr
```

同时移除了 `_ensure_printlog_param()` 函数，因为不再需要。

## 测试验证

### 测试 1: 参数过滤逻辑
✅ 验证通过：对于定义了 `params` 但没有 `printlog` 的策略类，`printlog` 参数会被正确过滤掉

### 测试 2: 没有 params 的策略类
✅ 验证通过：对于没有定义 `params` 的策略类，所有参数都会被正确过滤掉

### 测试 3: 简单的回测测试
✅ 验证通过：使用模拟数据的回测可以正常运行

## 影响范围
- 自定义代码回测接口（`/api/backtest/custom`）
- 所有使用 `run_backtest()` 函数的地方

## 兼容性
- ✅ 继承自 `BaseStrategy` 的策略类：仍然正常工作（`BaseStrategy` 定义了 `printlog` 参数）
- ✅ 直接继承 `bt.Strategy` 的策略类：现在可以正常工作（参数会被正确过滤）
- ✅ 现有的预置策略：不受影响
