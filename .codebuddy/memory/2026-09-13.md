## 因子选股器改造（阶段一完成）

用户想参照同花顺，把"复杂但不好用"的策略编辑/选股，重做成**因子选股器**——
自由组合已知因子筛股票，像同花顺一样好用。

### 方向对齐（多轮交流后确认）
- **核心需求**：因子选股器（自由组合因子 → 筛出股票列表），**不是**回测策略编辑器
- **条件逻辑**：扁平 AND（同花顺风格，不做 OR 嵌套）
- **范围**：选股器 + 策略编辑器**统一**成同一套"因子标签块"交互
- **刷新**：首次下载慢 + 之后改条件秒级

### 同花顺/东财秒级原理（用户要求分析，已交付）
核心是**把"慢"挪到盘后/后台，把"快"留给点条件那一刻**：
1. 数据全本地化（盘后同步，选股零网络请求）
2. 指标预计算（收盘后批量算好存库，选股只查表）
3. 预排序 + 索引（O(log n)，非 O(n) 遍历）
4. C++ 向量化 + 结果缓存 + 专门选股引擎
- 我们的落地思路：**数据/计算/筛选三层分离**——首次下载缓存（慢一次），
  之后对「指标宽表」做布尔筛选（秒级）
