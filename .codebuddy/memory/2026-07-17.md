## 实时选股池控制台报错排查
用户反馈实时选股池页面控制台报错：`Results-*.js` 中 `Cannot read properties of null (reading 'clientWidth')`、`visual/load/dual_ma` 与 `visual/load/bollinger` 404、`backtest/run` 500。

排查结论：
- **clientWidth 崩溃是根因（已修复）**：`frontend/src/components/KLineChart.tsx` 的 `ResizeObserver` 回调在图表容器卸载后读取 `ref.current!.clientWidth` 导致空引用；该组件与 EquityCurve 同属「回测结果/StockDetail」页，崩溃会污染全局 JS 上下文，连带使后续 `visual/load`(404) 与 `backtest/run`(被中断成 500) 表现为连锁失败。已给 KLineChart 的 handleResize 与初始化加 `if (ref.current)` 判空，并加固 EquityCurve。
- `visual/load/{key}` 404 属正常：预置代码模板（dual_ma/bollinger）非可视化规则，前端 VisualEditor.tsx 已 catch 降级，功能正常，仅控制台噪声。
- `backtest/run` 500 为偶发：手动复现稳定 200（返回真实数据）。后端日志显示 AKShare 拉取偶发 ProxyError 会降级模拟数据；特定股票/区间下可能触发回测异常。需用户提供触发时的股票代码+区间才能精确定位。

修复文件：frontend/src/components/KLineChart.tsx, frontend/src/components/EquityCurve.tsx
