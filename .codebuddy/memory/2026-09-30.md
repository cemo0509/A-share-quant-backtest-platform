## 新踩的坑：私有仓库不能用 raw.githubusercontent.com 核验

- 本仓库是私有仓库，raw 未授权返回 **404 页面**（不是文件真实内容），
  导致"下载内容 vs 快照"哈希全部判为"不同"，制造严重假象（一开始差点据此误判）。
- 正确做法：用 git 对象核验——`git fetch` 后比对 `origin/main` 与本地 HEAD / blob，不依赖 raw。

## 接口字段名备忘（实测，易踩）

- 回测 `POST /api/backtest/run` 用 **`strategy`**（不是 `strategy_key`），
  返回 `data.metrics`（收益率等）、`data.trades`、`data.equity_curve`、`data.data_source`。
- 策略列表是 `GET /api/strategy/list`（返回 `{status, data:[...]}`）。
- 选股器 `POST /api/screener/run` 返回 `data` **直接是数组**，另有 `total_scanned` / `matched`。
- PowerShell 里函数名**不要用 `SC`**（撞 `Set-Content` 别名）；`Invoke-WebRequest` 在
  非交互模式需加 `-UseBasicParsing`，否则报"朗读和提示功能不可用"。
