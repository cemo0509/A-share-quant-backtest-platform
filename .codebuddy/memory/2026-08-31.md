## 修复「报错过多」：网络异常降级改造

### 问题定位（从 backend/logs/backend.log）
用户截图报错多，日志显示两条真实根因：
1. `13:28:10` `stocks/intraday` 抛 **500**（`Connection aborted / RemoteDisconnected`）
2. `13:30:00` `datasource: eastmoney 失败: 无法连接通达信行情服务器` —— **文案张冠李戴**

### 根因
- **BUG-A**：`datasource.py` 用 `self.active_name`（实际生效源）记录错误，而非配置源 `_active_name`；且降级后未复位 `_active`，导致每次请求都重试已确认失败的源（拖慢响应 + 日志刷屏）
- **BUG-B**：数据类接口把「外部数据源不可用」一律映射为 500「服务器内部错误」，弱网/代理下前端持续飘红，且错误日志被噪声淹没

### 修复
- 新增 `backend/core/net_errors.py`：`is_network_error()`（类型+类名+消息关键字三重判定）、`degraded_payload()`（200+degraded 降级响应）
- `stocks.py` 5 个接口（search/kline/intraday/indicators/signals/market-state）、`data.py` 2 个、`market.py` 2 个接入网络降级
- `main.py` 全局 handler：网络异常 → **503 + WARNING**（未逐个改造的接口兜底），真实 bug 仍 500 + ERROR
- `datasource.py`：新增 `_demote_to_eastmoney()`，降级**粘性**（失败后 `_active` 复位东财）+ 日志用配置源名
- 前端 `StockDetail.tsx`：识别 `degraded` 标记 → `message.info` 轻提示，不再静默空白

## 核实 WorkBuddy 诊断「模拟数据标记失效」（部分属实，核心论断证伪）

来源：`C:\Users\22864\Desktop\诊断_模拟数据标记失效_2026-08-31.md`（WorkBuddy 从 GitHub 公开仓库读取源码后出具）

### 逐条核实结论

| 诊断主张 | 核实 | 证据 |
|---|---|---|
| ① `_generate_mock_kline` 设 `is_mock` | 属实 | data_loader.py:299 |
| ② `engine.run_backtest` 读标记返回 `data_source` | 属实 | engine.py:174,183 |
| ③ **attrs 丢失 →「一次降级永久洗白」** | **证伪** | 端到端实测 3 处均为 `is_mock=True` |
| ④ **前端根本不显示 `data_source`** | **不属实** | `Results.tsx:54-58` 明确显示（诊断只查了 `Backtest.tsx`，而结果页是 `Results.tsx`） |
| ⑤ 日志用 `logger.info` 应改 warning | 属实 | 静默失败不可追溯 |
| ⑥ **选股扫描无 mock 防护** | **属实（真问题）** | `_scan_inner` 完全不检查 `data_source` |

### 关键证伪依据
- 环境 **pandas 3.0.3**，`to_parquet()` **会保留** `df.attrs`（旧版 pandas 1.x 才会丢）
- 端到端实测链路：首次生成 → 落盘 parquet → 二次读缓存，**三步 `is_mock` 均为 True**
- WorkBuddy 按「to_parquet 不序列化 attrs」这一旧常识推断，**未实测**
- 因此「方案 A/B/C」三种缓存重构均基于错误前提，**未采纳**（避免过度治疗 + 牺牲离线能力）

### 已实施的针对性加固（采纳诊断中合理的部分）
1. **日志级别**：`_generate_mock_kline` 与降级分支 `logger.info` → `logger.warning`，写明「随机生成，不可作为策略有效性依据」
2. **选股扫描防护**（真问题）：`_scan_inner` 增加 `if bt_result.get("data_source") == "mock": return None`，杜绝随机假K线产生买入信号入选股结果
3. **缓存可见性**：`list_cache()` 返回 `is_mock` 字段；`DataManage.tsx` 增加「数据性质」列（红标模拟/绿标真实）+ 顶部 Alert 统计告警
4. **前端醒目提示**：`Results.tsx` 由 `Typography.Text` 小字升级为 antd `<Alert type="error" showIcon />` 常驻横幅

### 验证
- 标记机制回归测试 5/5 PASS（含引擎 data_source=mock 判定）
- 扫描防护 2/2 PASS（mock→跳过返回 None；real→正常入选）
- pytest 3/3、tsc 零错误、零 lint
