## 第四批大工程 4/6：P0-8 样本外验证（commit `11f25da`）

**核心设计**：参数搜索**只在样本内**进行（前 70%），样本外（后 30%）完全不参与调参。
若在全区间搜索再用后段验证，样本外数据已被参数"看过"，验证就失去意义（数据泄露）。

实现（`api/optimize.py`）：
- `_split_date()`：按**实际交易日序列**切分（非自然日），保证两段数据量可控；
  数据少于 120 个交易日则跳过验证（附原因）
- `_retention()`：保持率 = 样本外/样本内；样本内为负时无意义返回 None
- `_evaluate_overfit()`：三级判定
  - `danger`：样本内盈利但样本外亏损（最典型过拟合）
  - `danger`：收益保持率 < 30%
  - `warn`：夏普保持率 < 30%，或收益保持率 < 60%
  - `none`：表现一致
- `_run_validation()`：复用搜索阶段已有的样本内指标，**样本外只多跑一次回测**

`models/schemas.py` 新增 `OutSampleValidation` 模型，`OptimizeResponse` 加 `validation` 字段。

前端 `Optimize.tsx`：三栏卡片（样本内 / 样本外 / 保持率）+ 顶部告警条（error/warning/success）。
