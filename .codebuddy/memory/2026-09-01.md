用户选择「把他补全吧」（选项 A：补 codegen，而非标注草稿本）。

### 实现内容
新增 `backend/core/visual_editor/codegen.py`（约 600 行），把可视化条件树
（VisualRule）编译成可直接回测的 Backtrader 策略代码：

- **支持 17 个指标**：ma/ema/macd/kdj/boll/rsi/cci/wr/bias/vol/vol_ratio/
  obv/amt/turnover/price/high_low_range/rise_rate/new_high/new_low/ma_arrangement
- **支持 6 种操作符**：greater/less/cross_up/cross_down/equal/between
- **支持 3 种目标类型**：常数 / 价格 / 另一指标
- **买卖信号成对生成**：金叉买、死叉卖；非方向性条件（如 RSI 介于）卖出用取反；
  组合节点用德摩根律（AND 的否定是 OR）
- **指标实例化去重**：相同参数复用同一实例（签名缓存），避免重复计算

### API
- `POST /api/visual/codegen` — 规则 → 代码（含 ast.parse 语法校验）
- `POST /api/visual/run` — 规则 → 代码 → `load_strategy_from_code()` → `run_backtest()`

### 前端（VisualEditor.tsx）
- 新增「生成代码」按钮 → Modal 展示代码 + 复制 + **保存为自定义策略**
- 新增「立即回测」按钮 → 表单收集 symbol/区间/资金 → 回测后跳 `/results`

### 踩坑与修复（4 个）
1. **`get_or_create` 解包顺序反了**：factory 返回 `(lines, var)`，却按
   `(var, lines)` 解包 → var 变成 list。改为 `lines, var = factory(...)`。
2. **`CrossOver` 传了值而非 Line 对象**：`_target_expr` 返回带 `[0]` 的值。
   新增 `as_line` 参数，交叉场景返回 Line 表达式。
3. **目标指标周期丢失**：前端用 `ma20` 这类带周期标识，需解析出 period，
   否则「MA5 上穿 MA20」被编译成 MA5 上穿 MA5。新增 `_parse_target_indicator()`。
4. **沙箱缺内置函数**（**既有 bug，影响所有自定义代码回测**）：
   - 缺 `__import__` → `import backtrader` 抛 `ImportError`
   - 缺 `__build_class__` → `class` 定义抛 `NameError`
   - 修：`_get_safe_builtins()` 加白名单受限 `__import__`（含 `__future__`）+ `__build_class__`
5. **`load_strategy_from_code` 提前 pop 模块**（**既有 bug**）：
   `finally` 里 `sys.modules.pop(module_name)`，但 backtrader 的
   `metabase.donew()` 实例化策略时需要 `sys.modules[cls.__module__]` → KeyError。
   改为不 pop（模块常驻，体积极小）。`load_custom_strategy_class` 同样修复。
